2. # API 응답 정보(JSON) {#api-응답-정보(json)}

| Key      | Type       | Value          | Comment        |
| -------- | ---------- | -------------- | -------------- |
| err_code | String     | 응답 결과 코드 | default : NULL |
| message  | String     | 에러 메세지    | default : NULL |
| data     | JSON/array | 결과값         | default : NULL |
| count    | Int        | 데이터 개수    | default : NULL |

1. Success  
   \- 단일 데이터

| { “data” : { “xxx” : “xxxxx”} “count” : 1 } |
| :------------------------------------------ |

\- 다중 데이터

| { “data” : \[ { “xxx” : “xxxxx”}, { “xxx” : “xxxxx”}, \], “count” : 2 } |
| :---------------------------------------------------------------------- |

2. Fail

| { “detail” : { “err_code” : “1002”, “message” : “액세스 토큰이 만료되었습니다” } } |
| :--------------------------------------------------------------------------------- |
